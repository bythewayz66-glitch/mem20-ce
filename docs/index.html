mem20 Core Edition

Memory that knows the difference between what happened and what was imagined.

Grounded facts and simulated hypotheses never mix. Contamination rate on a clean store is 0.0. Index drift is reported, not hidden.

Install

pip install mem20-ce

Quickstart

from mem20_ce import MemoryEngine

engine = MemoryEngine()
engine.remember("the deploy key rotates on the first Monday")
engine.remember_simulated("perhaps it was already rotated")
print(engine.recall("deploy key"))
print(engine.contamination())  # contamination_rate: 0.0

Invariants

  • Simulated content never reaches grounded indexes
  • remember() is grounded-only by default
  • Promotion requires evidence
  • Reads never write the ledger
  • Index drift is a first-class diagnostic
